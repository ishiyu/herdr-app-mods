---
description: thread の起動本数を、全 project について日ごと・project ごとに出す（project-threads の coordinator 用）
argument-hint: "[日数（既定 14）]"
---

user が thread の起動本数を見たいと頼みました。引数は次の 1 行です（空なら引数なし）。

```
$ARGUMENTS
```

次の 1 コマンドを 1 回だけ実行してください。引数に日数（1〜366 の数）があればその数を渡し、空か数でなければ日数を省きます（既定の 14 日）。この command を Skill ツールで呼び直す必要はありません。

```
{bin}/thread-count {project} [日数]
```

成功したら、出力の表と箇条書きを書き換えずにそのまま user に示します（数え直さない・言い換えない。足すなら 1 行まで）。引数が数でなかったときは、既定の 14 日で出したことを 1 行で添えます。失敗したら出力の理由を 1 行で伝えます。
