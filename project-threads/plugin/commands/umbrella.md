user が `/pj-threads:umbrella` で umbrella を指定しました。引数は次の 1 行です（空なら引数なし）。

```
$ARGUMENTS
```

system prompt の「umbrella と次の一手」の節の `/pj-threads:umbrella` の扱いどおりに進めてください。この command を Skill ツールで呼び直す必要はありません。
